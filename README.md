# AI Talent Scouting Agent

This project is a simple AI-powered system that matches candidates with job descriptions using skill-based analysis.

## Features
- Job Description input
- Candidate matching based on skills
- Match Score & Interest Score
- Explainable output (matched skills)

## How it Works
- The system takes a job description as input
- It compares keywords with candidate skills
- Assigns a Match Score based on skill overlap
- Generates an Interest Score (simulated)
- Ranks candidates and shows matched skills

## How to Run

1. Install Streamlit:
   pip install streamlit

2. Run the app:
   streamlit run app.py
